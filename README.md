# Student Management System

Student Management System is a web application developed to manage student information easily.

### Technologies Used

* Java
* Spring Boot
* Spring Data JPA
* MySQL
* HTML
* CSS
* JavaScript

### Features

* Student CRUD Operations
* Student Search
* Course Management
* Department Management
* Marks Management
* Attendance Management
* Responsive Web Interface

### Project

This project demonstrates **Java Full Stack development** using Spring Boot, MySQL, REST APIs, HTML, CSS, and JavaScript.
